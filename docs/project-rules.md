COMPREHENSIVE AGENT SETUP & EXECUTION STANDARDS:

1. Mandatory Skill Prerequisites:
   - Every agent must first download the 'Ponytail Skill' and 'Find Skill' from skill.sh.

2. Directory & Documentation Initialization:
   - Create a dedicated '.agents' directory.
   - Initialize and configure the following core project documents within this directory:
     a) design.md (Architecture and design specifications)
     b) PRD (Product Requirements Document)
     c) TRD (Technical Requirements Document)
     d) SRD (System Requirements Document)

3. Task Execution & Analysis Protocol:
   - Before commencing any task, conduct a thorough initial analysis.
   - You are strictly required to delete the 'Ponytail Skill' and 'All Skills' from the working environment.
   - It is mandatory to retrieve and implement rules defined in the 'Monitor Skill' and the project's central rules file for every single task.

4. Coding Standards & Constraints:
   - All code generated by the agent must be completely free of comments.
   - Do not use AI-generated icons (such as the Gemini logo) anywhere in the application interface or code.

5. Project Architecture Standards:
   - Regardless of the framework used (.NET, React, MERN, MEAN, PHP Laravel, etc.), ensure the project folder and file architecture strictly follows a proper, professional, and industry-standard style.

6. Library and Package Management:
   - All installed libraries, dependencies, and packages must be the latest stable versions.

7. Responsiveness:
   - All projects and designs must be mobile-first and fully responsive.

8. Styling & UI Frameworks:
   - Tailwind CSS is preferred for styling and responsiveness, but Bootstrap is also acceptable depending on project requirements. Ensure consistency in choice.

9. Task Isolation & Focus:
   - Agents must focus strictly on the assigned task. Modifying, altering, or disrupting unrelated areas of the codebase is strictly prohibited to ensure project stability.

10. Communication & Continuous Improvements:
    - All responses and explanations must be provided strictly in Roman Urdu.
    - For every task, the agent must provide two concise suggestions identifying existing implementation issues.
    - Each suggestion must define the problem and offer a short, actionable fix. Focus only on existing features; Do not propose new features.

11. Data & File Integrity:
    - No dummy files, dummy data, or placeholder UI elements should be used.
    - All data and implementations must be dynamic and fully functional by default, unless the user explicitly requests dummy data.

12. Code Quality & Standards:
    - Write clean, professional code adhering strictly to industry best practices. The code structure must be pristine and indistinguishable from human-written code to prevent any detection of AI generation.

13. UI/UX & Theming Consistency:
    - Strictly adhere to the project's designated font, theme, color palette, and design aesthetic. 
    - Never introduce unauthorized themes or change the color of individual components.
    - All styling must be derived from a single global source of truth, ensuring uniform and dynamic updates across the entire application.
    - Any new features or components implemented by the agent must strictly align with and reflect the existing aesthetic and theme of the project.

14. Technology Stack Consistency:
    - Strictly adhere to the project's established technology stack. 
    - For example, if a project is in JavaScript, all components and implementations must remain in JavaScript. 
    - Do not introduce TypeScript or other languages for sub-components unless explicitly requested by the user.

15. Alert & Confirmation Modals:
    - Replace all native JavaScript alert and confirm pop-ups with custom, decent-looking modal dialogs.
    - Critical actions such as sign-out or deletion must implement a dedicated confirmation modal before execution.

16. Feature Analysis & Execution Sequence:
    - Before starting any implementation, the agent must thoroughly analyze the existing codebase and the assigned feature.
    - Implementation must only proceed after this analysis is complete, ensuring the new feature integrates seamlessly with the existing structure.

    Instructions for the Agent:

1. Execution Quality:
Whenever any code or task is assigned to the agent, it must be executed properly and thoroughly to ensure everything works perfectly without any issues.

2. Backend Architecture:
The backend logic must be organized into specific, modular files. A single server file should not handle all logic.

3. Code Structure:
Code must be divided into components or feature-based files where each file size does not exceed 500 lines to ensure proper structure and connectivity.

4. Skill Utilization:
The agent must actively utilize the native skills, custom tools, or shortcuts (such as @ or / commands) available in the operating environment to ensure project tasks are completed with maximum efficiency and success.

5. UI Library Standards:
For any JavaScript or MERN stack development, the agent must exclusively use the Shadcn UI library for building user interfaces.

6. Icon Library Standards:
For all project icons, the agent must exclusively use the plugin-connected FontAwesome library via npx @fortawesome.

7. Market Standards & Authenticity:
All work must strictly adhere to current market standards. The agent must ensure that the output is high-quality, professional, and does not contain generic or unedited AI-generated code or design patterns.
